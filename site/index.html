Blunderbase
Demo Docs GitHub

Every game you play, analysed. Every blunder, remembered.

Blunderbase is a personal chess database. It pulls in your games from Lichess, Chess.com and FICS, runs Stockfish and Maia over each one as it arrives, and keeps the lot in a library you own — with an AI coach that reads the same library you do.

  • Free and open source, MIT
  • Self-hosted in one container
  • One owner, one password, your data on your disk

What it does

Imports itself

Connect a Lichess, Chess.com or FICS account and sync it with one press, or on a schedule you set. PGNs drop in too.

Two engines, two opinions

Stockfish grades every move. Maia, the human-move model, shows what players at 1100 to 2000 would have done instead — so a "blunder" is measured against people, not just against perfection.

A coach that reads your library

An MCP server is built in. Point Claude or any MCP client at it and talk through a game on a live board the browser and the coach share.

Your own opening book

An explorer with win rates over your own games, side by side with the Lichess database, and reference games you can add to the library to study.

Notes, lines, a repertoire

Annotate positions, save variations, and keep the lines you actually play. Everything searchable.

Engines wherever they are

Stockfish on the server, in the browser as WebAssembly, or on a remote runner — your idle office machine, say. The queue does not care which.

Stats that name the habit

Blunder rate by opening, by time control, by phase of the game, by clock. Recurring mistakes, so you can stop making them.

One file, yours

The library is a single SQLite file. Verified backups, a full export, and nothing phoning home.

Around the library

Run it yourself

# One container. Your library lives in the volume.
docker run -d --name blunderbase -p 8765:8765 \
  -v blunderbase-data:/data \
  ghcr.io/philphilphil/blunderbase:latest

Open it in a browser, choose a password, connect an account. That password is also the coach's key. Stockfish ships in the image; TLS, reverse proxies, remote engine runners and the CLI are in the docs.
