Game organization · concept 2 of 3

Folders

A folder is a place, and every game lives in exactly one. Games you have not filed live in Unfiled, which is what the library opens on. A league game that goes into its folder is out of the way until you go and look for it.

This is the most literal reading of “put games like that into a special folder”. It separates by default, and that default is exactly what makes it expensive: every screen that counts games has to ask which folder it is counting.

Verdict

What it gets right

  • Matches the words in the issue exactly, so there is nothing to explain: a folder, and the games in it.
  • Separation is real and automatic. The everyday list stays everyday, and a league season is one click away.
  • ‹ › walking a folder is a natural way to review a season round by round.

What it costs

  • One place per game: a league loss cannot also be in “Tough losses”. Anything cross-cutting needs a second idea anyway.
  • Every counting screen (Stats, the dashboard, the explorer, MCP’s get_stats) has to learn a folder scope and pick a default. The wrong default hides the games you care most about.
  • Nesting is next. Once there are folders someone asks for sub-folders, and trees are a lot of UI for a library of this size.
  • A second “where does this game live” axis next to Mine / Others, which already answers a similar question.
