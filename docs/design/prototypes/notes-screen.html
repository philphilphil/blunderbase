Notes, four ways

The screen groups notes by game. That is the wrong axis — and it is also what makes the columns look broken. Here is the case against it, then four layouts that do not need it, drawn with the same six notes so they can be judged against each other.

Counted from data/blunderbase.db today. The notes in the mockups below are illustrative — the nine real ones are test rows averaging six characters — but the shape they are drawn to is the shape the table actually has.

Why the grouping has to go

A game is where a note was written, not what it is about

Grouping by game turns this page into a second index of games, which /games already is. It also puts the most reusable notes — the ones pinned to a position, which resurface in every game that reaches it — into a leftovers bin at the bottom called Opening lines and loose notes. A third of all notes land there.

And it is the direct cause of the odd-looking columns. A heading forces a row break, so a game carrying one note takes a full row and leaves the rest of it empty. At 1.5 notes per noted game, most rows are two-thirds hole. The columns are not the problem; the headings between them are.

There is a quieter argument too. Nine notes against 9,620 games means this screen is being designed ahead of its data. Whatever it does at ten notes it must also do at five hundred, so the ordering wants to be a control the reader turns, not a structure baked into the layout.

Variant one

Stream

One column, newest first, no groups at all. Time is the only ordering that is always true of a note, so it is the one the page falls back on — marked by thin date rules that cost no vertical space and cannot punch holes in a layout. The column is capped at a readable measure instead of spanning the monitor, and the board sits at 68px, big enough to recognise a structure.

Holds up

  • Never ragged, at nine notes or nine hundred — there is no cell to leave empty.
  • Reads at one measure, so a long note and a one-liner look like the same object.
  • The smallest change from what ships today: delete the grouping, cap the width.

Costs

  • Uses the left half of a wide monitor and leaves the rest empty.
  • Finding a specific note is search, not browsing — nothing is clustered.
  • Boards stay small; you recognise a position, you do not read one.

Variant two

Reading desk

Split the two jobs. The left pane is an index — one line per note, a colour stripe for what kind it is, nothing else — and the right is the note itself at full size, with a board you can actually read a position off and the provenance spelled out underneath. Editing happens in the reading pane, where there is room for it.

Variant three

Contact sheet

The columns kept, the headings dropped, and the board promoted to the top of the card where it does the work the text cannot: you find the note about the Berlin by seeing the Berlin. Cells fill in order with nothing to break the flow, so the grid finally looks like a grid. Text is clamped to four lines — the card is a way in, not the place you read.

  • Uses the whole screen, and packs without gaps once the headings are gone.
  • Visual recall: the position is the index, which is how chess memory works.

  • Clamping hides the end of every note longer than four lines.
  • Equal-sized cells imply notes are equally important. They are not.

Variant four

Shelves

Keep grouping, but on an axis that means something: the tag, which is the owner's own word for what a note is about. Each shelf is a horizontal strip, so a topic with one note costs one row rather than one row and two holes — the failure mode that made game grouping look wrong is structurally impossible here. Untagged notes get the last shelf, and it is the shelf that tells you to start tagging.

The same shelf works on opening instead of tag — Ruy Lopez: Berlin, Caro-Kann — which needs no tagging discipline at all, because the games already carry an ECO code and the explorer can name a position's opening. That is a backend change rather than a layout one, which is why it is a footnote and not a fifth variant.

Orthogonal to all four

What a note carries, whichever layout wins

Where it came from

The move and the game it was written on, as a link that opens that game there — and a mark when the game is a model game rather than one of yours. A note pinned to a position turns up wherever that position does, and unattributed advice is advice from nobody.

Where else it applies

How many games in the library pass through the position, linking into the explorer rooted there. That count is the difference between a note about one game and a note about a line you keep playing.

Who wrote it

A conclusion the coach reached over MCP and a reminder you left yourself should not look identical. The amber edge stays.

Decided · 2 September 2026

Stream and contact sheet, behind a toggle

Picked by the owner off this page and built the same day. The stream is what the screen opens in — one column, every note whole — and the sheet is a keystroke away for the browsing mood. The reading desk is not built; it is the answer to a note count this library does not have yet, and it can be a third option on the same toggle if browsing ever stops working.

What both of them dropped is the grouping. Time cuts the list instead, as rules that take a line rather than a row, which is what a date can do and a game heading could not.

1

Delete the game grouping. One flat list, newest first, with date rules. This alone fixes the columns, because it removes what was breaking them.

2

Cap the reading measure at about 46rem instead of spanning the canvas, and let the board grow to 68px. The wide screen is not an obligation.

3

Put ordering in the filter row beside the view switch — newest, by opening, by tag — so the axis is the reader's to change and no one layout has to be right for every library size.

4

Keep the sheet as the second view, un-grouped, board on top, text clamped — and let it rewrite and forget a note like the stream does, because a view you can only read from is a view you leave.

5

Hold the desk until the note count justifies it, and until there is a phone answer for a two-pane screen.
