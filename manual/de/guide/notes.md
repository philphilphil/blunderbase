# Notizen

## Woran hängt eine Notiz? { #what-does-a-note-stick-to }

An einer Stellung, nicht an einer Zugnummer. Schreib sie mit `N` auf dem Partie-Bildschirm,
und sie erscheint in jeder deiner Partien, die diese Stellung erreicht, egal in welcher
Zugfolge. Eine Notiz kann Schlagwörter tragen. Auch eine Notiz, die du in einer Musterpartie
oder einer Referenzvariante schreibst, gehört dir und bleibt erhalten.

Oder an einer ganzen Partie, ohne Stellung: über die Zeile *Partie* ganz oben im Reiter
**Notizen** des Partie-Bildschirms (`⇧N`) oder über **Diese Partie** in einer
Fernschachpartie.
Solche Notizen erscheinen nur bei dieser einen Partie – siehe
[Eine Partie analysieren](game.md#write-a-note).

Wo immer eine Notiz geschrieben wird – Partie-Bildschirm, Explorer, Live-Brett,
Fernschachpartie, Notizseite –, speichert **Enter** sie, und **Shift+Enter** beginnt eine
neue Zeile. Ein Feld, das beim Wegklicken speichert, tut das weiterhin.

## Wo tauchen sie auf? { #where-do-they-show-up }

Unter dem Brett jeder Partie, die die Stellung erreicht, im Explorer unter **Deine Notizen
zu dieser Stellung** und auf dem Live-Brett. Die Zugspalte markiert Züge, zu deren Stellung
eine Notiz existiert. Eine Partie, über die du schon einmal nachgedacht hast, sagt es dir
also.

## Die Notizseite { #the-notes-page }

**Notizen** sammelt alles, was du und dein Assistent geschrieben habt, die neueste zuerst,
gegliedert durch eine Linie je Zeitabschnitt (*Früher in diesem Monat*, *August 2026*).

Die Zeile über der Liste beginnt mit dem Umschalter für die Ansicht. **Liste** zeigt jede
Notiz in voller Länge, zwei nebeneinander; **Tafel** ein Raster aus Stellungen mit
gekürztem Text; **Tabelle** eine Zeile pro Notiz mit ihrer Herkunft: Zug, Gegner samt
Wertung, Ergebnis und, in einem Fenster ab 1440 Pixeln Breite, wann die Partie gespielt
wurde und die Tags. Die gewählte Ansicht merkt sich die Seite.

Danach folgen die Filter, jeder ein Knopf, der ein kleines Feld aufklappt: **Tags**,
**Betrifft** (woran die Notiz hängt), **Gegner** und **Ergebnis** der Partie, zu der sie
entstand, **Partie**, **Geschrieben** (wann) und **Geschrieben von** (du in der App, dein
Assistent über MCP oder das Live-Brett). Ein gesetzter Filter wird blau und nennt seinen
Wert, etwa *Tags: Endspiel*; sein **×** hebt ihn auf, **zurücksetzen** hebt alle auf. Das
Suchfeld **Notizen filtern…** am Ende der Zeile durchsucht den Text der Notizen selbst.

Auf einer Notiz sagen die kleinen grauen Wörter oben (*Partie*, *lose*, *über MCP*,
*vor 28 T.*) nur, was sie ist. Die Tags unter dem Text (*#Endspiel*) sind dagegen Knöpfe:
Ein Klick zeigt nur noch Notizen mit diesem Tag. Der Stift schreibt die Notiz um, der
Papierkorb löscht sie nach einer Rückfrage. Unten öffnet **Geschrieben bei …** die Partie
bei diesem Zug und **In 3 deiner Partien** die Stellung im Explorer. In der Tabelle
klappt ein Klick auf eine Zeile die ganze Notiz an Ort und Stelle auf; ein Klick auf den
Namen des Gegners zeigt nur noch Notizen zu Partien gegen ihn.

## Notizen exportieren { #export-notes }

**Exportieren** oben rechts gibt alles aus, was die aktuellen Filter zeigen. Wähle
**Markdown** für eine Datei zum Lesen oder **PGN** für eine Datei, die ein Schachprogramm
öffnet; darin werden Notizen zu Kommentaren und gespeicherte Varianten zu Varianten.
Solange keine Notiz passt, ist der Knopf ausgegraut.
