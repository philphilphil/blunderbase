# Settings

## Change the language

The account menu, under **Language**, switches between English and German. It is a setting
of the browser rather than of the account, so a phone in German and a desk in English is an
ordinary arrangement. The page reloads under you, so save an open note first.

## Switch the theme

Also in the account menu: **Dark**, **Light** or **Match the system**. Dark is the default.

## Set up the board

The gear under the board, or `S`, opens **Board settings**. They apply in this browser
only.

| Setting | Choices |
|---|---|
| **Arrows** | Draw the engine's suggestions on the position shown, or not |
| **Evaluation graph** | Filled curve, bars, dots or none; and which marks it carries |
| **Line preview** | What pointing at an engine line does: arrows, ghost pieces, a replay on the board, a small board beside the line, or nothing |
| **Sound** | A click as each move lands, and how loud |

## Replay the tour

**Show the tour again** in the account menu restarts the five-step tour. **Back** and
**Next** walk it, **Skip** or `Esc` ends it. A step whose control is not on screen is
skipped.

## The command palette

⌘K opens the command palette. With nothing typed it lists the pages; type two characters
and it also finds games, opponents, openings and notes, your saved filters and the
statistics reports. `↵` opens what is highlighted.

## Every keyboard shortcut

`?`, or the keyboard button in the title bar, prints the keys that apply to the screen you
are on.

### Anywhere

| Key | Does |
|---|---|
| `⌘K` | Search games, opponents, openings and notes |
| `?` | This list |
| `⌘1` … `⌘5` | Dashboard, Games, Explorer, Notes, Stats |
| `⌘⇧I` | Import |
| `Esc` | Close whatever is open |

### Analysing a game: moving about it

| Key | Does |
|---|---|
| `←` `→` | One move back, one move on |
| `↑` `,` | The previous flagged move |
| `↓` `.` | The next flagged move |
| `⇧←` `⇧→` | Five moves back, five moves on |
| `Home` `End` | The starting position, the last move |
| `Space` | Play the game through |
| `[` `]` | Previous and next game in your games list |

### Analysing a game: the board

| Key | Does |
|---|---|
| `F` | Flip the board |
| `H` | Hints — the board's arrows and the engine columns |
| `E` | The live engine on this position |
| `↵` | Play the engine's move onto the board |
| `S` | Board settings |
| `Esc` | Back to the game |

### Analysing a game: the game itself

| Key | Does |
|---|---|
| `N` | Write a note about this position |
| `Q` | Queue a quick pass |
| `D` | Queue a deep pass |
| `C` | Copy the PGN |
| `T` | Swap the move column between Moves and Flagged |

### The library table

| Key | Does |
|---|---|
| `↑` `↓` | Move along the rows |
| `Home` `End` | The first and the last row |
| `↵` | Open the game under the cursor |
| `/` | Search the library |

### Walking a line in the explorer

| Key | Does |
|---|---|
| `←` | Back one move |
| `→` | Forward, back down the line you just left |
